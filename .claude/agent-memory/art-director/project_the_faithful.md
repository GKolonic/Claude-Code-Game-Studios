Mobile narrative game. One-on-one missionary conversations. Portrait orientation. Godot 4.6, Compatibility Renderer (2D mobile target). Illuminated manuscript aesthetic.

7-colour palette: Vellum (#F5F0E8), Scripture Gold (#C9A84C), Embers Red (#8B2E2E), Iron Ink (#2C2416), Pilgrim Blue (#3A5A7C), Ash Grey (#9E9A8E), Hearthlight (#E8C090).

Art bible locked at `design/art/art-bible.md`. GDDs in `design/gdd/`.

**Why:** Single source of truth so art direction decisions start from the locked visual system, not from memory of an earlier session.

**How to apply:** Always read `design/art/art-bible.md` before making color, lighting, or style decisions. The palette hex values in this memory entry are from the brief — verify against art-bible.md if precision is needed; the bible's values are authoritative.
